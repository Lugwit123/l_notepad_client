# L Notepad 更新日志

## Unreleased

### 新增功能
- ⚓ Markdown 预览支持**文档内跳转**：`[说明 ↓](#标题-slug)` 点击即滚到对应标题（GitHub 风格 slug，中文/标点与 GitHub 一致，如 `#d1--d2-活例getformfields接口可用但对参数极敏感`）；激活块源码态标题同样能匹配，找不到锚点不误动
- ⚡ Markdown 预览**输入性能**大幅提升：渲染态打字/退格不再整篇重建文档，只替换内容变化的那一块（1501 块 / 168KB 实测单键 **653ms → 6.3ms**）；另加逐块渲染缓存，重复块不再重复渲染
- 🔀 版本对比（并排 diff）：版本下拉框右侧新增「⇄ 差异」下拉框 ×2 + 「对比」按钮，默认 = **最新 vs 上一版**，点开后在双栏对话框里并排看改动
  - 行背景标色：删除红（左栏）、新增绿（右栏）、修改黄（两栏）；顶部显示 `新增 x 行 / 删除 y 行 / 修改 z 行`
  - 两栏滚动同步；只读，不会改动编辑器与版本库内容
  - 对比栏一律用**源码态**（`.md` 走 `markdown` 源码高亮而非预览），保证行号与源码 1:1 对齐
  - 版本数不足两个时按钮自动禁用；超长内容（> 20000 行）只对比前 20000 行并提示
  - 新文件 `version_diff_dialog.py`（`build_side_by_side` / `diff_stats` 纯函数，可单测）；设计见 `doc/版本对比与reload版本生成_设计.md`
- 🖱️ 滚动条加粗可抓（`style.qss`，全应用生效）：条身 10px → **12px**，手柄（滑块）设 **最小长度 40px**，长笔记内容下不再被压成几像素抓不住；手柄配色加深并补 hover/pressed 反馈
- ❌ 硬盘上被删除的文件条目**明确标记**：外部文件 / IPC 文件分组（含「★ 收藏」置顶项与文件夹悬停浮层）中，文件已不存在时前缀显示 `✕`（红色、悬停提示「文件已不存在——点底部「刷新」清理」）；正在查看的文件被外部删除时也会立即重排列表并提示
  - 树的渲染走自定义 delegate，✕ 条目单独用告警色（只认渲染时的 ✕ 前缀，不做每帧 I/O）
- 🔄 底部「刷新」按钮：重扫笔记的同时**清理硬盘上已删除的外部/IPC 文件条目**，状态栏报告清理数量；当前正在查看的文件被清理时回到最近笔记/空态
- 📥 笔记列表/笔记树支持从资源管理器**拖入文件**：拖入即自动归类到「外部文件」分组并打开第一个
  - 拖拽悬停时状态栏提示「松开即可加入「外部文件」分组」
  - 多文件按拖入顺序置顶；重复拖入同一文件不重复添加，只置顶并提示「已在「外部文件」中」
  - 目录/不存在的路径/网络 URL 会被忽略并提示；拖入前若当前笔记有未保存改动，沿用既有的切换前自动保存
  - 内部分组拖拽（笔记调序）不受影响：只拦截 uri-list 拖放数据
- 📂 笔记列表右键菜单新增「打开文件所在文件夹」：笔记树/列表、外部文件、IPC 文件条目均可在资源管理器中定位（文件用 `/select,` 选中，文件已删除则退到最近的已存在父目录）

### 问题修复
- 🔄 外部文件被外部修改后点「重载」**不生成新版本**：重载只刷新了编辑器与磁盘快照，未写入版本库，导致磁盘上的新内容永远进不了版本历史（对比时看不到这次改动）
  - 根因：版本库写入只挂在「打开文件」(`_set_external_file_editor`) 与三个保存路径上，`_reload_local_file_from_disk` 漏写
  - 修复：重载成功后补 `_record_version(kind, ref, title, text)`（`text` = 刚从磁盘读出的全文，避免 markdown 预览态取到非权威内容），位置在 `_record_loaded_local_file` 之后、`_sync_version_combo_on_open` 之前，版本下拉随即显示新版本
  - 内容未变时 `history_store.add_version` 自动去重，重复点重载不会刷出版本
- 🔄 外部修改弹窗后「笔记查看组件没更新」：
  - 根因：markdown 预览层（`_MarkdownLivePreview`）持有自己的源码副本，重载只写了隐藏的正文文档；且预览态 `toPlainText()` 读的是预览层 → 界面不更新，连后续 Ctrl+S 也会存回旧内容
  - 修复：`code_editor.apply_text_with_cache` 在预览态写入后显式重渲染预览层（保留滚动位置）
  - `_reload_local_file_from_disk` 增加「可见文本 == 磁盘内容」校验，不一致就强制刷新（预览态走 `show_markdown_preview`，源码态走 `setPlainText`），并打印 `[本地文件监控] 强制刷新编辑区`
- 🔄 本地文件被外部修改后无提示（笔记 / 外部文件）：
  - 根因一：`ui.py` 的 `MainWindow` 是 `L_FramelessMainWindow` 外壳的**内容子控件**，Qt 的 `WindowActivate` 只发给顶层窗口 → `changeEvent` 里的检查永不触发。改为在顶层窗口 `self.window()` 上 `installEventFilter` 过滤 `WindowActivate`/`ActivationChange`
  - 根因二：原先只在窗口重新激活的瞬间检查一次，且只对 `.log` 文件生效。新增 `QFileSystemWatcher`（文件 + 父目录）+ 1.5s `QTimer` 轮询兜底，窗口在前台时实时发现外部写盘
  - 编辑器有未保存修改（dirty）时不再静默跳过，改为明确提示「重载会丢弃你当前未保存的修改」
  - 快照比对由单一 mtime 扩展为 (mtime, size)；文件被外部删除时给出状态提示而非弹重载框
  - 新增 `[本地文件监控]` 诊断日志（记录快照 / 检测到外部修改 / 提示结果）
- 🔄 本地文件被外部修改后回到前台无提示：原先只对 `.log` 文件做变更检测，笔记与外部文件完全不检测
  - 检测范围扩展为「当前编辑的本地文件」（笔记 / 外部文件 / IPC 文件）
  - 本程序自身保存（Ctrl+S / 自动保存）后刷新快照，不会误报外部修改
- 🌐 网址收藏页列表：图标 20px（favicon 本体，**画布贴合无透明留白**）+ 1px 间距 → 行高 21px，行与行之间不再发虚；文件夹/命令收藏页保持紧凑（14px / 22px）
  - 之前图标框 28px 里 favicon 只占约 2/3（画布 44 缩到 28），四周透明边造成「行距还是很大」的观感 → 网址页改用 `tight=True` 画布：图标填满图标框、云角标压在右下角内侧
  - `_icon_with_cloud` 支持按 `base_px` 等比例缩放画布与云角标，不再固定 22px 画布内嵌 14px 图标（此前图标尺寸被硬编码裁死）
  - 行高由 `_favorites_icon_size() + _FAV_ITEM_GAP_PX` 统一推导（`_favorites_item_height`），图标与间距不再各写各的
  - 列表紧凑样式改为按实际控件名生成（网址页是 `url_favorites_list`，此前 `#folder_favorites_list` 选择器对它不生效）
  - 切换收藏种类时重新应用样式，favicon 缓存边长 32 → 64px，放大后不发虚

## v2.2.0 (2026-09-01)

### 安全修复
- 🔒 服务器日志 API（`/api/logs*`）全部收紧为管理员专属：原先任意登录用户可读取/篡改/删除服务器日志
- 🔒 登录 Cookie 改为服务端 `Set-Cookie` 下发（`HttpOnly` + `SameSite=lax`），防 XSS 窃取 token；登出改为服务端清 cookie
- 🔒 修复共享列表存储型 XSS：共享用户名改用 DOM `textContent` 渲染，不再拼 `innerHTML`
- 🔒 后端默认监听地址 `0.0.0.0` → `127.0.0.1`（对外暴露需显式 `--host`，生产走 nginx `/note` 反代）

### 问题修复
- 🐛 修复新建笔记后连续 Ctrl+S 重复创建：旧正则只匹配数字 ID，现按 303 重定向的最终 URL 更新地址栏与表单 action
- 🐛 修复笔记改名后注册表/共享关系不迁移：改名后笔记从列表消失、共享关系悬空，现随改名同步迁移
- 🐛 修复 `POST /web/{path}/delete` 被 `POST /web/{path}` 路由吞掉导致删除按钮 403（路由注册顺序）

### 新增功能
- ✨ 接入本机 Auth Service（`http://localhost:8080/auth`，文档 `/auth/docs`）
- ✨ 新增服务日志查看器 `/web/logs`（管理员）：日志级别着色（INFO/WARN/ERROR/CRITICAL）、行号、行数上限、关键字过滤、下载、SSE 实时跟踪追加（Dozzle 式 tail -f）
- ✨ `/web?q=` 搜索升级为服务端全文检索（单文件 2MB 上限），不再只匹配 8KB 摘要
- ✨ 编辑页增加未保存离开提醒（beforeunload）

### 改进优化
- 🚀 笔记列表 TTL 缓存（3s + 写入失效），避免每请求全目录扫描
- 🚀 日志读取默认只读文件尾部（`?tail=` 字节，上限 4MB），大日志不再整读进内存
- 🚀 SQLite 开启 WAL + busy_timeout；改为每请求独立连接，消除共享连接的线程竞态
- 🚀 启用 GZip 压缩（≥1KB）
- ♻️ 后端按领域拆分路由：`routers/{notes,logs,admin,accounts,web}.py` + `deps.py` 依赖注入（FastAPI 官方模板模式）
- ♻️ 模板抽 `base.html` + `static/app.css` + `static/app.js` 公共层，去除 5 个模板重复的样式与登出脚本
- ♻️ 移除 `db.py` 中已废弃的 `notes` 表 CRUD 死代码
